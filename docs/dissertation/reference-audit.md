# Stage 5 Phase C Reference Audit

## Audit method and result

The Phase C reference set was rebuilt from sources actually used in the manuscript. Bibliographic details were checked on 19 August 2026 against publisher pages, DOI landing pages, official proceedings/repositories, original dataset sites or official software documentation. Formatting follows the UWE Bristol Harvard author-date conventions, including `no date` for undated web documentation and access dates for online sources.

The final set contains **21 unique in-text sources and 21 reference-list entries**. The bidirectional audit found **zero citation-to-reference mismatches**, **zero reference-to-citation mismatches**, and **zero unresolved bibliographic markers**.

## Corrections and exclusions

- An older proposal cited the Ji article with the wrong issue/article combination. The publisher record confirms *Sensors* **21(10): 3558**, DOI `10.3390/s21103558`; the working manuscript uses the corrected record.
- Older proposal bibliographies were treated as leads rather than inherited wholesale. Sources without a direct role in the final argument, including unused dataset catalogues, planned tools and broader reproducibility surveys, were not retained.
- No reference is retained solely because it appeared in an earlier dissertation. No entry is marked `REQUIRES REFERENCE REVIEW` or `[REFERENCE VERIFICATION REQUIRED]`.
