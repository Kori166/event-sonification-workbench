## Architecture and dependency decision

Decision 0017 freezes the Phase 2 architecture. A Python `InspectionModel` accepts only a
`ValidatedWorkbenchSession`, loads the immutable verified JSON artefacts once and builds indexes by
frame, time, event ID and cue ID. A standard-library `ThreadingHTTPServer` exposes a loopback-only,
read-only service. Package-local HTML, CSS and JavaScript provide the browser presentation.

No production dependency was added. There is no web framework, Node build, database, analytics,
authentication, upload or write endpoint. Workbench Session Contract `0.1.0`, Stage 1 event formats,
Stage 2 cue/audio formats and the Stage 3 report contract remain unchanged.

## Launch path and runtime binding

With the ignored local `.env` configured, run:

```powershell
python -m event_sonification_workbench.cli inspect-session
```

The command loads only the supported runtime variables, derives the retained
`<dataset>/run-a/{events,cues,audio}` package roots from `STAGE2_EVIDENCE_ROOT` when package-specific
roots are absent, validates the complete session before constructing the inspection model, and then
serves a path-free address at `http://127.0.0.1:8765/` by default. Existing process environment
values take precedence over `.env`. Non-loopback hosts are rejected.

## Read-only routes

| Route | Projection |
|---|---|
| `GET /api/session` | Verified session identity, component state, counts, timing and logical media summary |
| `GET /api/frames/<frame>` | Recorded image dimensions and Stage 1 geometry/metadata for one frame |
| `GET /api/frames/<frame>/image` | The bound source image for that frame |
| `GET /api/timeline?start=<s>&end=<s>` | Half-open, maximum-two-second event/cue/suppression window |
| `GET /api/trace?cue_id=<id>` | Cue to event to logical annotation/row to configuration to render sample chain |
| `GET /api/evaluation` | Direct projection of the verified Stage 3 report or an explicit unavailable state |
| `GET /api/audio` | Exact verified WAV bytes with single-range HTTP support |

Routes accept identifiers, frame numbers or bounded numeric time windows only. They cannot select
arbitrary filesystem paths. JSON ordering is deterministic, failures use stable path-free codes,
and security headers restrict content to same-origin package assets.

## Synchronisation and frontend behaviour

The browser audio element's `currentTime` is the sole live playback clock. The animation loop reads
that value and derives `frame = floor(currentTime * frame_rate)`, bounded to the recorded 600-frame
sequence. Play and pause use the same audio element; seeking and one-frame stepping assign its
`currentTime`. There is no independent playback timer or advancing frame counter.

The source image and SVG overlay share the authoritative 1920 by 1080 coordinate space. Native
Stage 1 geometry is displayed unchanged, including permitted boxes that extend slightly outside the
image boundary. A one-second window around the audio time presents Stage 1 event, Stage 2 cue and
Stage 2 suppression lanes with a cursor derived from the same audio clock. Window contents come from
prebuilt indexes; JSON files are not reparsed per frame.

Selecting a nearby cue or timeline marker displays cue signal values, linked event/frame/track,
logical native annotation and physical row, preset/renderer identities, and the exact render start
and end sample. The metric panel displays the committed report's coverage, density, overlap,
traceability, timing and reproducibility fields and labels their source. It performs no evaluation
calculation.

## Evidence boundary and limitations

The interface is read-only inspection/demonstration infrastructure. It does not provide participant,
accessibility, usability, navigation, perceptual-effectiveness or safety evidence. R20 therefore
remains open and controlled. Phase 3 cross-dataset presentation, clean-environment release
verification and release packaging have not started.

The branch must not be merged and the eight Phase 2 checklist items must not be accepted until the
browser gate, final privacy audit and hosted CI are complete.
