# Third Party Dataset Attribution

## Purpose And Scope

This repository supports inspection of *A Reproducible Workbench for Event Based Sonification of
Annotated Video Datasets*, a non-commercial MSc research artefact. Dataset imagery is supporting
media for the inspection interface. The project does not claim ownership of that imagery and does
not present its deployment bundle as a replacement distribution of either complete dataset.

## MOT17 And MOTChallenge

- Dataset: MOT17
- Retained inspection sequence: MOT17-02-DPM
- Frames included in the deployment bundle: 600
- Original project: [MOTChallenge](https://motchallenge.net/)
- Licence identified by the original project: [Creative Commons Attribution-NonCommercial-ShareAlike
  3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/)
- Project citation: Milan et al., “MOT16: A Benchmark for Multi-Object Tracking” (2016),
  [arXiv:1603.00831](https://arxiv.org/abs/1603.00831)

The complete MOT17 dataset is not stored in Git or included in the deployment bundle.

## KITTI Vision Benchmark Suite

- Dataset: KITTI Tracking
- Retained inspection sequence: 0000
- Frames included in the deployment bundle: 154
- Original project: [KITTI Vision Benchmark Suite](https://www.cvlibs.net/datasets/kitti/)
- Licence identified by the original project: [Creative Commons Attribution-NonCommercial-ShareAlike
  3.0 Unported](https://creativecommons.org/licenses/by-nc-sa/3.0/)
- Relevant citation: Andreas Geiger, Philip Lenz and Raquel Urtasun, “Are we ready for Autonomous
  Driving? The KITTI Vision Benchmark Suite”, CVPR 2012

The complete KITTI dataset is not stored in Git or included in the deployment bundle.

## Acquisition Record

The local research copies used during development were obtained from publicly accessible Kaggle
mirrors:

1. [KITTI Tracking mirror](https://www.kaggle.com/datasets/leducnhuan/kitti-tracking/data)
2. [MOT17 mirror](https://www.kaggle.com/datasets/wenhoujinjust/mot-17)

Dataset ownership, attribution and licensing remain associated with the original MOTChallenge and
KITTI projects rather than the mirror uploaders. This notice records the attribution and release
scope already used by the deployment bundle. It is not an automated legal determination about
publication or redistribution.

Dataset terms are separate from any future licence selected for project authored source code.
